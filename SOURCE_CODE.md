# Código fuente y oferta de fuentes

Nodus Imago es software AGPL-3.0-only. Su código fuente correspondiente, scripts y configuración de compilación están en:

https://github.com/jorgepb96/nodus-imago

Cada distribución debe corresponder a una revisión o etiqueta accesible de ese repositorio y ofrecer sus fuentes completas, incluidos cambios locales. No se debe publicar un binario construido con cambios privados sin publicar también sus fuentes correspondientes.

El código adaptado de Nodus Research conserva su licencia y atribución. Consulta `docs/REUSE.md`, `THIRD_PARTY_NOTICES.md` y `LICENSE`.
